🖥️ SpecX – Custom PC Builder & Component Explorer

SpecX is a modern PC configuration and component browsing web application built using React, Tailwind CSS, and React Router.
It allows users to explore pre-built systems, PC components, gaming accessories, and build their own custom PC configuration with a clean and responsive UI.

🔹 Core Features

🧩 Pre-Built PC Systems

🖥️ Component Categories

-CPU

-GPU

-Motherboard

-RAM

-Storage

-Power Supply

-Cabinet

🎮 Gaming Accessories Section

🧾 Detailed Product View

🛒 PC Builder (Add & Review Components)

📱 Fully Responsive UI

⚡ Fast navigation using React Router

🎨 Tailwind CSS modern UI
